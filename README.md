# 沿海居民台风实况信息网站

面向沿海居民，提供台风名称、当前位置、移动方向、中心风力以及所在地官方分级预警。

已接入广东气象公开台风列表、实况路径、预测路径和地区台风预警快照。没有活动台风时显示空状态，不以历史或演示台风冒充实况。

## 本地运行

运行 `python scripts/fetch_data.py` 更新 `data/latest.json`，再运行 `python -m http.server 8000 --bind 127.0.0.1`，访问 http://127.0.0.1:8000 。网页通过 fetch 读取 JSON，需要 HTTP 服务；不再支持直接双击 HTML 加载数据。Python 仅使用标准库，无需安装依赖。

页面支持多台风选择、六个广东地区预警查询、预测路径开关、文字路径和大字模式。路径图按真实经纬度绘制，为线性坐标示意，不含海岸线和行政边界，不用于导航。

主要文件：`index.html` 为页面结构，`styles.css` 为响应式样式，`app.js` 为数据展示与交互，`scripts/fetch_data.py` 为采集器。预警颜色从官方接口标题读取，不根据中心风力计算。六个区的接口查询结果只代表所选区，不代表全市。

## 自动同步与部署

`.github/workflows/update-and-deploy.yml` 在 main 推送、手动执行和每小时 UTC 第 7、22、37、52 分钟运行（间隔 15 分钟，避开整点拥堵）。Actions 调度可能延迟，不承诺准点。公开仓库长期无活动时，GitHub 可能停用计划任务，需在 Actions 检查状态。

仓库 Settings → Pages → Source 选择 GitHub Actions。工作流测试解析器、抓取数据、提交快照、上传站点构建产物并部署 Pages。仅 index.html、styles.css、app.js 和 data/latest.json 进入站点构建产物。数据提交使用 GITHUB_TOKEN，不需要自建访问令牌。

接口失败保留上次成功的数据和时间，写入错误状态，并在发布错误状态页面后将工作流标记失败。页面超过 45 分钟未同步将提示延迟；实况点超过 6 小时另行提醒。这些是产品提示阈值，不是官方预警阈值。

验证命令：`python -m unittest discover -s tests -v`、`node --check app.js`。

## 数据来源与边界

- 官方页面：https://wxc.gd121.cn/html/qxfw/typhoon/typhoon2/dist/
- 台风列表：该站 `../data/typhoonindex.json`。
- 台风实况与预测：`{IntlID}_BCGZ.json` 和 `{IntlID}_BCGZ_forecast.json`，按官方页面请求方式读取。
- 地区预警：官方台风页面使用的 `servletcityweatherall4` 地区查询响应中的 `yjrows`，只保留台风相关标题与正文。

以上为公开网页使用的数据端点，并非已取得服务保障的开发者 API；接口可能变化，未发现可据此声称的开放授权或服务承诺。仅低频查询并注明来源，不复制底图、第三方密钥或原站代码。正式运营前需核实转发使用条件。

预报有效时间 = 起报时间 + leadtime 小时。原始实况机构代码与预报机构代码分别保留。缺失数值显示暂无数据，数据异常不能推断为无台风或无预警。

## 基本原则

以权威气象机构发布的信息为依据；标明来源与时次；区分实况和预测；所在地预警按官方发布展示。台风中心风力不代表居民所在地风力，页面不得据此自行发布官方预警。
